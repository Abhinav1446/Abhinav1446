### [Aurora Email Automation System](https://github.com/Abhinav1446/Aurora-Email-Automation)

An intelligent email automation system that:
- Classifies incoming emails into 6 categories using **Google Gemini 2.5 Flash**
- Generates **tailored AI replies** based on email type
- Scores **confidence level** of each classification
- Filters **spam** automatically
- Assigns **priority** (High / Medium / Low)

- Logs everything to a **live Google Sheets dashboard**

**Tech:** n8n · Google Gemini AI · Gmail API · Google Sheets · JavaScript

### [Benza Resume Screener](https://github.com/Abhinav1446/benza-resume-screener)

A 3-version AI-powered resume screening system that evolved from Google Form input to full PDF processing:

**Version 1** — Google Form input, AI scoring, selection/rejection emails

**Version 2** — PDF resume upload via webhook, automatic PDF text extraction, structured AI parsing

**Version 3** — Everything in v2 plus personalised improvement suggestions for rejected candidates — Gemini generates a warm, detailed email explaining exactly what skills the candidate is missing and how to improve them

- Scores resumes using weighted criteria (Skills 40% · Experience 30% · Projects 20% · Education 10%)
- Automatically sends personalised emails to selected and rejected candidates
- Logs all scores, decisions and reasons to Google Sheets

**Tech:** n8n · Google Gemini AI · Gmail API · Google Sheets · JavaScript · PDF Processing
